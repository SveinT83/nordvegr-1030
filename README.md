# Nordvegr 1030

Nordvegr 1030 is a historically grounded digital reconstruction and game project focused on Norway around AD 1030, beginning with the Innherred / Trøndelag region.

The project is being built in Unity and is intended to grow incrementally: first a focused playable area, then additional historically relevant locations and systems.

## Project goals

- Build a believable reconstruction of landscape, settlements, buildings, vessels, animals, people and everyday life around AD 1030.
- Prefer documented historical and archaeological evidence over modern fantasy conventions.
- Keep the project modular so the geographic scope can expand later.
- Support community contributions through the official repository.
